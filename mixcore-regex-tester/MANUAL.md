# 正则测试器 用户手册

## 产品简介

正则测试器是一个**纯本地离线**的正则表达式调试工具：输入正则与测试文本，即可实时看到匹配高亮、分组结构与匹配位置，还内置了常用表达式库，支持保存自己的常用正则。

## 快速上手

- 安装后在 MixCore「插件中心 → 已安装插件」中找到并打开「正则测试器」；
- 打开即有一个示例（日期正则 + 测试文本），在顶部输入框直接修改正则，下方文本区会实时高亮匹配；
- 在右侧「常用表达式库」点击任意一条，即可一键载入对应的正则、修饰符与示例文本。

## 功能与操作

### 实时匹配高亮

1. 在顶部输入正则表达式（自动带 `/…/` 外壳），下方文本区会**实时**高亮所有匹配；
2. 修饰符 `g i m s u y` 以按钮形式提供，点击即开/关；未开启 `g` 时只高亮第一处匹配；
3. 表达式非法时会在输入框下方显示错误原因，且不会产生匹配。

### 分组可视化

1. 右侧「匹配结果」中，顶部**位置图**按比例展示每个匹配在文本中的位置；点击某处匹配后，位置图内还会细分展示各分组的区间；
2. 匹配列表点击任意一处，下方「分组明细」表格展示该处的完整匹配与每个捕获组（含命名组 `<name>`）的内容与区间；
3. 每个分组用不同颜色标识（组 0 为强调色），选中匹配在文本区中会以**分组颜色分色显示**；
4. 表格中每个分组均可一键复制内容，匹配列表也支持单条复制与「复制全部」。

### 常用表达式库

1. 「内置」页签提供邮箱、URL、手机号、IPv4、日期、时间、身份证号、颜色、中文、数字、HTML 标签、空行等常用表达式；
2. 在「我的」页签，点击「保存当前」可将当前正则 + 修饰符 + 测试文本保存到自定义库（数据仅本插件可见）；
3. 顶部工具栏的「保存到表达式库」按钮会直接跳转到「我的」并聚焦命名输入框；
4. 自定义条目可随时删除；顶部搜索框可按标题 / 表达式 / 描述过滤。

### 其他

- 「复制正则」复制当前表达式；「清空文本」清空测试文本；
- 顶部「跟随系统 / 浅色 / 深色」可切换明暗主题，默认跟随系统，选择会被记住。

## 数据说明

- 自定义表达式库与主题偏好保存在插件自己的数据目录（`store`），自包含，不访问其他插件或平台数据；
- 所有匹配计算均在本地完成，不产生任何网络请求；
- 删除或重装插件前，如需保留自定义表达式请先手动记录。

## 常见问题

- **为什么没有高亮？** 检查表达式是否合法、测试文本是否为空、是否未勾选 `g`（未勾选时只显示第一处，且文本区只有一处高亮）。
- **为什么某个分组显示“未匹配”？** 可选分组（如 `(ab)?`）在部分匹配中未参与捕获，属正常现象。
- **浏览器直接打开页面无效？** 插件运行在 MixCore 的 webview 中，需要经「插件中心 → 加载开发插件」或导入 `.mixplugin` 使用。

## 卸载说明

在「插件中心 → 已安装插件」中卸载「正则测试器」，插件目录与数据会一并删除。
