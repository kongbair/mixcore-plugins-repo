# SQL 格式化器 用户手册

## 产品简介

SQL 格式化器是一个**纯本地离线**的 SQL 处理工具：左侧输入 SQL，右侧实时得到格式化结果（关键字高亮、缩进换行、子查询缩进），也支持压缩去除多余空白；「SQL 示例」独立成页，内置多种常用语句。

## 快速上手

- 安装后在 MixCore「插件中心 → 已安装插件」中找到并打开「SQL 格式化器」；
- 顶部页签切换到「📚 SQL 示例」，点击左侧任意示例，右侧预览 SQL，点「使用此示例」即载入编辑器并回到格式化页；
- 左侧输入 SQL，右侧实时显示格式化结果。

## 功能与操作

### 输入与实时格式化

1. 左侧输入框为**纯文本输入**（不做高亮），输入内容右侧实时显示格式化结果；
2. 顶部可设置**方言**（MySQL / PostgreSQL / SQLite）、**缩进**（2 空格 / 4 空格 / Tab）、**关键字大小写**（大写 / 小写 / 保持）；
3. 格式化结果带**语法高亮**：关键字（蓝）、字符串（绿）、数字（橙）、注释（灰斜体）、函数（紫）分色显示，并按方言识别引号（MySQL 反引号、PG/SQLite 双引号标识符、SQLite 方括号）；
4. 开启「压缩」后输出为单行紧凑 SQL，并移除注释；
5. 「应用结果到输入」把格式化结果写回左侧输入框，可继续编辑。

### SQL 示例（独立页面）

1. 顶部页签「📚 SQL 示例」进入示例页，内置 12 条常用语句（查询、JOIN、聚合、子查询、增删改、建表、CASE、窗口函数、索引、UNION）；
2. 左侧列表点击条目，右侧实时预览（带高亮）；顶部搜索框可按标题 / 描述过滤；
3. 点击「使用此示例」把该 SQL 载入编辑器并自动回到格式化页；
4. 格式化设置（方言 / 缩进 / 大小写 / 压缩）会自动保存，下次打开保持。

### 复制

- 「复制结果」一键复制格式化 / 压缩后的 SQL。

## 数据说明

- 格式化设置保存在插件自己的数据目录（`store`），自包含，不访问其他插件或平台数据；
- 所有格式化与高亮均在本地完成，不产生任何网络请求；
- 删除或重装插件前，如需保留输入内容请先手动复制。

## 常见问题

- **为什么输入框不高亮？** 输入框定位为纯输入；语法高亮在右侧格式化结果中展示。
- **为什么 `LEFT JOIN` 被拆成两行？** 请确认使用的是新版本；格式化器已保证 JOIN 前缀不拆散。
- **双引号内容被当作标识符/字符串异常？** 不同方言对双引号解释不同，请在顶部选择正确的方言。
- **浏览器直接打开页面无效？** 插件运行在 MixCore 的 webview 中，需要经「插件中心 → 加载开发插件」或导入 `.mixplugin` 使用。

## 卸载说明

在「插件中心 → 已安装插件」中卸载「SQL 格式化器」，插件目录与数据会一并删除。
