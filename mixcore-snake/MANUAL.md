# 贪吃蛇（mixcore-snake）

双人同屏贪吃蛇游戏插件，支持键盘与手柄双控制。

## 玩法

- 进入游戏先显示首页：选择单人 / 双人模式后开始（选择会被记住）；单人只有一条蛇（P1）
- 游戏中按 P 暂停，可「退出游戏」返回首页；结束后也可「返回首页」
- 双人：两名玩家在同一棋盘竞技：P1 从左侧出发，P2 从右侧出发
- 棋盘上同时有 3 个随机食物，先到先得；吃到 +1 分、尾巴平滑 +2 格
- 撞墙 / 撞自己 / 撞对方（含已死亡蛇的残留身体）判负
- 一方出局后另一方继续；双双出局时按分数定胜负
- 速度档位（低/中/高）与等级加速；双人最高分分别记录

## 操作

### 键盘

| 玩家 | 按键 |
| --- | --- |
| P1 | W 上 · A 左 · S 下 · D 右 |
| P2 | ↑ ← ↓ → |

> 单人模式 P1 也可使用方向键。

- P / Enter：开始 / 暂停 / 继续
- R：重新开始
- 空格 / Shift：按住加速

### 手柄（Gamepad）

| 手柄 | 控制 |
| --- | --- |
| 手柄 1 | P1（左摇杆 / 十字键转向，A / Start 暂停，RT / RB 加速） |
| 手柄 2 | P2（左摇杆 / 十字键转向，RT / RB 加速） |

## 音效

- 背景音乐：开局后循环播放，暂停/结束时同步暂停或停止
- 死亡音：蛇死亡时播放；吃食物 / 开始有提示音
- 右上角 🔊/🔇 总开关；⚙️ 设置可分别调节背景音乐 / 吃食物音 / 死亡音 / 开始音音量

## 设置

- 右上角 ⚙️ 打开设置：吃食物音 / 死亡音 / 开始音音量，速度档位（低/中/高）
- 右上角 🔊/🔇 音效总开关、☀️/🌙 主题切换，选择会被记住

## 主题

默认跟随系统明暗主题，可手动切换并记忆。

## 安装

在 MixCore「插件中心 → 导入插件」选择 `mixcore-snake-1.0.0.mixplugin`。
