# 编解码工具箱 · 用户手册

## 产品简介

「编解码工具箱」是一款**纯本地离线**的编码转换工具，集中处理日常开发中最常用的五类操作：Base64、URL、JWT、Hash 摘要与时间戳互转。所有计算均在本地完成，不产生任何网络请求，无需联网。

## 快速上手

1. 在 MixCore「插件中心 → 已安装插件」中找到并打开「编解码工具箱」；
2. 顶部页签选择所需功能（Base64 / URL / JWT / Hash / 时间戳）；
3. 输入内容即实时计算，点击「复制结果」或行内「复制」即可复制到剪贴板；
4. 右上角可切换「跟随系统 / 浅色 / 深色」主题，选择会被记住，下次打开自动生效。

## 功能与操作

### Base64

- **编码 / 解码**：文本与 Base64 互转，支持中文（UTF-8）；
- **标准 / URL 安全**：URL 安全变体（Base64URL，无 `+/` 与 `=` 补位）适合 JWT、URL 参数场景；
- 操作：复制结果、⇄ 互转（输入输出交换并自动切换方向）、清空、粘贴输入。

### URL

- **编码 / 解码**：
  - 组件（`encodeURIComponent` 语义）：空格转 `+`，适合参数值；
  - 整体（`encodeURI` 语义）：保留 `:/?#` 等字符，适合完整 URL；
- **Query 解析**：粘贴 URL 或纯 QueryString 自动解析为参数表格，可增删改参数并实时生成新的 QueryString。

### JWT

- 粘贴 JWT（`header.payload.signature` 三段）自动解码；
- 展示 Header / Payload（格式化 JSON）、Signature（base64url）；
- 若含 `iat` / `nbf` / `exp` 时间声明，展示本地时间与「已过期 / 未过期 / 尚未生效」状态；
- **仅解码，不做签名校验**（如需校验请使用其他工具）。

### Hash

- 支持 MD5 / SHA-1 / SHA-256 / SHA-512，可单独启用或关闭；
- 输入文本（UTF-8）逐字符实时计算十六进制摘要；可选大写输出；
- 注意：Hash 是**单向**摘要，无法还原原文。

### 时间戳

- **时间戳 → 时间**：输入秒或毫秒时间戳，自动换算本地时间、UTC、ISO 8601、星期与相对时间；
- **时间 → 时间戳**：选择本地日期时间，自动换算秒 / 毫秒时间戳；
- 「当前」按钮一键填入当前时间，秒 / 毫秒结果均可单独复制。

## 数据与隐私

- 本插件**不保存任何输入内容**：不使用数据库，无历史记录；
- 仅 `store` 保存一项「主题选择」（跟随系统 / 浅色 / 深色），用于下次启动恢复；
- 所有计算本地完成，无网络请求，输入不会离开本机。

## 权限说明

- `store`：持久化主题选择；
- `clipboard`：复制结果、粘贴输入（剪贴板读写仅在你点击按钮时发生）。

## 常见问题

- **报「mixcore 未注入」？** 插件必须在 MixCore 环境中运行，直接用浏览器打开页面无效。
- **解码 Base64 报错？** 确认内容是否为合法 Base64；若含 `-_` 字符，请切换到「URL 安全」变体。
- **JWT 解码失败？** 确认是完整三段式 JWT（`header.payload.signature`），且每段为合法 JSON。
- **时间戳换算无结果？** 输入需为数字（可含负号或小数），超出可表示范围会提示无效。

## 卸载说明

在「插件中心 → 已安装插件」中卸载「编解码工具箱」，插件目录会一并删除；本插件未使用数据库，无残留业务数据。
