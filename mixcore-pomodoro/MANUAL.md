# 番茄钟用户手册

## 产品简介

番茄钟是一个基于「番茄工作法」的专注计时插件：把工作切分为 **25 分钟专注 + 5 分钟短休** 的循环，每完成 4 轮专注进入一次 **15 分钟长休**，帮助你保持节奏、减少分心。

适用场景：需要深度专注的工作 / 学习（写代码、写作、阅读、备考等）；数据完全保存在插件自己的数据目录（LMDB），本地自包含，不依赖网络。

## 快速上手

1. 在 MixCore「插件中心 → 已安装插件」中找到并打开「**番茄钟**」；
2. 点击中央的圆形 **开始** 按钮，开始第一轮专注；
3. 倒计时结束后自动进入休息，并弹出**系统通知**提示下一阶段；
4. 点击系统通知可回到插件窗口；界面底部会记录你的完成情况。

## 功能与操作

### 1. 开始专注

1. 打开插件，确认顶部徽标显示「专注」；
2. 点击圆形 **开始** 按钮（显示 ▶ 图标）；
3. 圆环开始收缩，中央显示剩余时间（`分:秒`，超过 1 小时显示 `时:分:秒`）；
4. 倒计时归零时自动进入下一阶段并弹出系统通知。

> 按钮状态说明：待开始显示 ▶（开始）；计时中显示 ⏸（暂停）；暂停后再次点击继续计时。

### 2. 暂停 / 继续

1. 计时过程中点击 **⏸** 按钮暂停，剩余时间保持不变；
2. 再次点击 ▶ 按钮从暂停处继续。

> 暂停后窗口关闭再打开，会恢复暂停状态和剩余时间。

### 3. 跳过 / 重置

- **跳过**（⏭）：跳过当前阶段，直接进入下一阶段；被跳过的专注**不计入**统计；
- **重置**（↺）：把当前阶段重置为完整时长，回到待开始状态。

> 重置不会清空今日 / 累计统计，只重置当前计时。

### 4. 阶段循环与进度

- 默认节奏：**专注 25 分钟 → 短休 5 分钟**，每完成 4 轮专注进入 **长休 15 分钟**；
- 顶部徽标显示当前阶段：`专注` / `短休` / `长休`；背景与圆环颜色随阶段变化（专注=红、短休=绿、长休=蓝）；
- 圆环下方的圆点表示本轮循环进度：实心圆 = 已完成的专注轮次，高亮圆 = 正在进行；
- 专注阶段时，圆环中央会显示「第 N / M 轮」。

### 5. 系统通知

1. 每个阶段结束时弹出系统通知（「专注完成」/「休息结束」），正文说明下一阶段；
2. **点击通知**会打开 / 回到插件窗口；
3. 若窗口关闭期间计时恰好到点，重新打开窗口时会**自动补记完成**并进入下一阶段（不会自动开始）。

### 6. 自定义设置（右上角齿轮）

打开设置后可调整：

| 设置项 | 含义 | 取值范围 |
| --- | --- | --- |
| 专注（分钟） | 每轮专注时长 | 1-180 |
| 短休（分钟） | 每轮短休时长 | 1-60 |
| 长休（分钟） | 长休时长 | 1-90 |
| 长休间隔（轮） | 每完成多少轮专注进入一次长休 | 1-12 |
| 自动开始休息 | 专注结束后自动开始休息 | 开 / 关 |
| 自动开始专注 | 休息结束后自动开始专注 | 开 / 关 |
| 阶段结束提示音 | 阶段结束时播放提示音 | 开 / 关 |
| 窗口置顶 | 插件窗口始终显示在最前 | 开 / 关 |

> 注意：时长修改对**进行中的阶段**不生效，下一次进入该阶段时生效；超范围输入会自动取边界值。

### 7. 窗口置顶

- 点击工具栏**图钉**按钮快速开启 / 取消置顶；
- 也可在「设置 → 窗口置顶」中开启（会被记住，下次打开保持）。

### 8. 统计

- 界面底部显示三项：**今日完成**（个数）、**今日专注**（总时长）、**累计完成**（个数）；
- 统计数据按天记录，跨天自动切换到新的一天；
- 只有完整跑完的专注阶段才会计入「完成个数」与「专注时长」，跳过不计。

### 9. 暗黑模式

- 默认**跟随系统主题**自动切换；
- 点击右上角月亮 / 太阳按钮手动切换；
- 手动选择会被记住，下次打开保持。

## 数据说明

- 数据保存在插件自己的数据目录（LMDB），**自包含**，不依赖网络；
- 存储内容：
  - 偏好设置（各阶段时长、长休间隔、自动开始、提示音、置顶、主题）；
  - 计时状态（阶段、剩余时间、循环进度，用于窗口关闭后恢复）；
  - 每日与累计统计（完成个数、专注时长）；
- 删除或重装插件前，请先确认不需要保留统计记录（卸载会一并清除数据）。

## 常见问题

- **计时到点但没有系统通知？** 请确认系统已允许 MixCore 的通知权限；插件内的提示音可在「设置 → 阶段结束提示音」开关。
- **修改时长后当前计时没变化？** 时长修改对进行中的阶段不生效，进入下一阶段后生效。
- **窗口关闭后计时怎么处理？** 窗口关闭即停止；重新打开窗口时，若关闭期间恰好到点，会自动补记完成并进入下一阶段，不会自动开始。
- **跳过会不会计入统计？** 不会。只有完整跑完的专注阶段会计入完成个数与专注时长。
- **窗口置顶点了没反应？** 请确认系统允许插件窗口置顶；也可在「设置 → 窗口置顶」中开启。
- **计时不太准（后台 / 最小化时）？** 插件按时间戳计算剩余时间，最小化或后台不会失真；长时间挂起后回到窗口会自动校正。
- **暗黑模式没有跟随系统？** 若曾手动切换过主题，插件会记住你的选择；点击月亮 / 太阳按钮切回「跟随系统」即可。
- **本插件有全局快捷键吗？** 没有。所有操作都在插件窗口内完成，不占用系统快捷键。

## 卸载说明

在「插件中心 → 已安装插件」中卸载「番茄钟」，插件目录与数据会一并删除。
