# 待办事项（mixcore-todo）

简单的本地待办插件

## 功能特性

- 添加 / 完成 / 删除待办事项
- 数据保存在插件自己的 LMDB 中，自包含

## 安装

1. 打开 MixCore **插件中心 → 插件商店**，搜索「待办事项」并点击安装；或
2. 下载 `mixcore-todo-1.0.0.mixplugin` 后，在 **插件中心 → 已安装插件** 点击「导入插件」选择该安装包。

## 权限说明

| 权限 | 用途 |
| ---- | ---- |
| db | 插件数据存储（LMDB） |

## 数据

- 插件数据独立存放在 `<数据目录>/plugin-data/mixcore-todo/`（LMDB + config.json），自包含；
- 卸载插件时数据目录一并删除，如需保留请先备份。

## 源码

源码位于 MixCore 主仓库 `plugins/mixcore-todo/` 目录，商店分发使用构建产物。
