# 俄罗斯方块（mixcore-tetris）

经典俄罗斯方块游戏插件，支持手柄与键盘双控制。

## 玩法

- 7 种方块（I / O / T / S / Z / J / L）随机出现（7-bag 洗牌，分布均匀）
- 左右移动、旋转（带踢墙）、软降、硬降
- 一次消 1/2/3/4 行分别得 100/300/500/800 × 等级分
- 每消 10 行升 1 级，下落速度随等级加快
- 「暂存」可换出当前方块，每次落定只能换一次；「下一个」预览后续 3 个方块
- 最高分按玩家分别记录

## 操作

### 键盘

| 按键 | 功能 |
| --- | --- |
| ← / →（或 A / D） | 左右移动 |
| ↓（或 S） | 软降 |
| ↑ / W / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| 空格 | 硬降 |
| C（或 Shift） | 暂存 |
| P（或 Enter） | 开始 / 暂停 / 继续 |
| R | 重新开始 |

### 手柄（Gamepad）

连接手柄后自动识别，按键映射：

| 手柄按键 | 功能 |
| --- | --- |
| 左摇杆 / 十字键 左右 | 左右移动 |
| 左摇杆 下 / 十字键 下 | 软降 |
| A / Y | 顺时针旋转 |
| B / LB | 逆时针旋转 |
| X | 暂存 |
| RB / RT | 硬降 |
| Start | 开始 / 暂停 / 继续 |
| Back | 重新开始 |

> 手柄输入基于浏览器标准 Gamepad API；若运行环境不支持手柄，键盘操作可完整游玩。

## 主题

右上角按钮在浅色 / 深色主题间切换，默认跟随系统主题；选择会被记住。

## 消行特效

- 消行时整行高亮闪烁，方块粒子迸发、得分飘字
- 双消/三消显示横幅，四消显示 TETRIS! 并轻微震屏

## 音效

- 背景音乐：游戏开始后循环播放，暂停/结束时同步暂停或停止
- 落地音：方块落定时播放
- 消除音效：消行时播放；游戏结束有提示音
- 右上角 🔊 / 🔇 按钮切换音效开关（同时控制背景音乐），选择会被记住

## 玩家

- 进入游戏先选择已有玩家，或新建玩家（名称最多 12 字符）
- 每个玩家的最高分独立记录
- 首页排行榜按最高分排序展示所有玩家
- 游戏页可随时「切换玩家」返回首页

## 设置

- 右上角 ⚙️ 打开设置弹窗
- 音量：可分别调节背景音乐 / 消除音效 / 落地音
- 速度：低 / 中 / 高（默认中），影响方块下落速度
- 设置会被记住

## 安装

在 MixCore「插件中心 → 导入插件」选择 `mixcore-tetris-1.0.0.mixplugin`。
