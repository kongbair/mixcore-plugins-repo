# 俄罗斯方块（mixcore-tetris）

经典俄罗斯方块游戏插件，支持手柄与键盘双控制，含玩家体系与积分历史统计。

## 玩法

- 首页选择单人 / 双人模式（或进入「玩家积分」统计页）
- 开局前有 3-2-1 倒计时与 START! 缩放动画，倒计时结束才落下第一个方块
- 双人选择页：玩家 1 在左、玩家 2 在右，各自独立选择（不可重复），双方都选完后任意玩家按 A 进入确认页
- 确认页：显示双方玩家，仅「开始游戏」「返回」两个按钮
- **双人模式**：分屏同时游玩，看谁先挂掉——任一棋盘顶出即结束，存活方获胜，可再来一局
- 7 种方块（I / O / T / S / Z / J / L）随机出现（7-bag 洗牌，分布均匀）
- 左右移动、旋转（带踢墙）、软降、硬降
- 一次消 1/2/3/4 行分别得 100/300/500/800 × 等级分
- 每消 10 行升 1 级，下落速度随等级加快
- 「暂存」可换出当前方块，每次落定只能换一次；「下一个」预览后续 3 个方块

## 玩家

- 进入游戏先选择已有玩家，或新建玩家（名称最多 12 字符）
- 每个玩家的最高分独立记录
- 首页排行榜按最高分排序展示所有玩家

## 积分历史统计

- 每局游戏结束都会记录一条积分：时间、积分、玩家
- 首页「玩家积分」进入统计页：
  - **积分走势**：折线图按每名玩家第 N 次对局展示积分走向（横轴为局数）
  - **玩家对比**：直方图对比所有玩家的最低分 / 平均分 / 最高分
  - **积分详情**：表格查看每条记录，可按玩家、时间（今天 / 近 7 天 / 近 30 天）过滤，可多选删除

## 操作

### 键盘

| 玩家 | 按键 |
| --- | --- |
| P1 | A / D 移动 · W 旋转 · S 软降 · F 硬降 · Q 反向 · C 暂存 |
| P2 | ← / → 移动 · ↑ 旋转 · ↓ 软降 · 空格 硬降 · Z 反向 · Shift 暂存 |

> 单人模式两套键位都可用。P 暂停 · R 重新开始。

### 手柄（Gamepad）

- 手柄 1 控制 P1，手柄 2 控制 P2（左摇杆 / 十字键移动，A/Y 旋转，X 暂存，RB/RT 硬降，Start 暂停，Back 重开）
- **页面按钮导航**：在首页 / 玩家页 / 确认页 / 积分统计页 / 暂停 / 结束中，十字键或左摇杆上下移动焦点，A / Start 确认，Back 返回

> 手柄输入基于浏览器标准 Gamepad API；若运行环境不支持手柄，键盘操作可完整游玩。

## 主题

游戏为暗黑主题（唯一模式），界面适配窗口全屏 / 最大化。

## 消行特效

- 消行时整行高亮闪烁，方块粒子迸发、得分飘字
- 双消/三消显示横幅，四消显示 TETRIS! 并轻微震屏

## 结算界面

- 游戏结束时「游戏结束 / 获胜」标题与得分放大显示：渐变霓虹 + 祝贺粒子动画，得分数字滚动递增
- 结算按钮 3 秒后出现，避免误触直接重开；重开 / 返回前可完整预览当局分数

## 音效

- 背景音乐：游戏开始后循环播放，暂停/结束时同步暂停或停止
- 落地音：方块落定时播放
- 开局倒计时滴答与 START! 有合成提示音
- 消除音效：消行时播放；游戏结束有提示音

## 安装

在 MixCore「插件中心 → 导入插件」选择 `mixcore-tetris-1.6.0.mixplugin`。
