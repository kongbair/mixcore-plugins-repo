# 工作项目用户手册

## 产品简介

工作项目插件集中管理本地 Git 项目：查看分支、概览 GitLab 合并请求（MR），并可直接从分支创建 MR。

## 快速上手

「新建项目」填入名称和本地 Git 仓库路径，选中项目后即可看到分支列表；点击右上角「配置」填好 GitLab 地址与访问令牌后，可查看合并请求。

## 功能与操作

### 项目管理

- **新建项目**：名称 + 本地路径（可点「选择目录」）；
- **编辑 / 删除**：列表项右侧铅笔 / 垃圾桶按钮；
- **搜索**：按名称或路径过滤。

### 分支查看

- 选中项目后自动列出本地分支（基于 Git 命令实时读取）；
- 使用分支区域的搜索框按名称实时过滤分支；
- 在某个分支上**右键**，可复制分支名、复制 `git checkout <分支名>` 命令，或选择「创建合并请求」。

### GitLab 配置

1. 选中项目后点击右上角「配置」；
2. 填写 **GitLab 地址** 与 **访问令牌（PRIVATE-TOKEN）**；
3. 地址可留空，插件会尝试从项目 remote.origin.url 自动识别；
4. 填入令牌后自动加载项目列表并匹配当前项目，选择后保存。

### 合并请求

- 列表显示“我创建的 + 指派给我的”MR，包含源分支 → 目标分支、作者和更新时间；
- 点击右侧按钮在浏览器中打开 MR。

### 创建合并请求

右键分支 → 创建合并请求：

1. 源分支自动填充为右键的分支；
2. 选择**目标分支**（默认 master / main）；
3. 填写**标题**（自动生成）与**描述**（可选）；
4. 选择**指派人**（可选，自动记住上次指派的人）；
5. 点击「创建」。

## 数据说明

- 项目列表与 GitLab 配置保存在插件自己的数据目录（LMDB）；
- GitLab 访问令牌本地保存，仅用于访问你的 GitLab 服务。

## 常见问题

- **MR 不显示？** 检查 GitLab 地址、令牌和项目关联是否正确；未配置时插件会给出提示。
- **分支读不出来？** 确认项目路径是有效的本地 Git 仓库。
- **令牌安全吗？** 令牌只存在本机插件数据中，不会上传到任何第三方。

## 卸载说明

在「插件中心 → 已安装插件」中卸载，项目列表、GitLab 配置与令牌会一并删除。
