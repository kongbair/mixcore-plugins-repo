# cron校验器用户手册

## 产品简介

cron校验器是一个纯前端工具插件：输入 cron 表达式，实时校验其合法性，并预览后续 N 次运行时间。适用于编写/排查定时任务表达式时快速验证与确认触发时刻。所有计算均在本地完成，不发送任何数据。

## 快速上手

- 安装后在 MixCore「插件中心 → 已安装插件」中找到并打开「cron校验器」；
- 在输入框中输入 cron 表达式（如 `*/5 * * * *`），下方会实时显示校验结果与后续运行时间；
- 默认预览 5 次，可通过胶囊按钮（1 / 5 / 10 / 20）或步进器调整为 1–20 次。

## 功能与操作

### 表达式校验

- 支持标准 **5 字段**：`分 时 日 月 周`（如 `*/5 * * * *`）；
- 支持 **6 字段**：首字段为秒（如 `*/10 * * * * *`）；
- 合法时输入框右侧显示绿色 ✓，并附人类可读描述（如「每 5 分钟」「工作日 09:00」）；
- 非法时显示红色提示，并逐条列出**字段级错误**（如「第 2 个字段（时）：值越界：24（范围 0-23）」）；
- 空输入不报错，显示灰色占位提示；
- 校验为实时反馈（200ms 防抖）。

### 支持的语法

| 语法 | 说明 | 示例 |
| --- | --- | --- |
| `*` | 任意值 | `*` |
| `*/n` | 步长 | `*/5`（每 5 分钟） |
| `a-b` | 区间 | `1-5`（周一到周五） |
| `a,b,c` | 列表 | `0,30` |
| `a-b/n` | 区间步长 | `0-30/10` |
| `?` | 等价 `*`（仅日/周字段） | `0 0 ? * *` |
| `L` | 最后一天（日） / 最后一个星期几（周） | `0 0 L * *`、`0 0 * * 5L` |
| `W` | 最近工作日（日字段） | `0 0 15W * *`、`0 0 LW * *` |
| `#` | 当月第 n 个星期几 | `0 9 * * 1#2`（每月第二个周一） |
| `@yearly/@monthly/@weekly/@daily/@hourly` | 常用别名 | `@daily` |

### 运行时间预览

- 基于**当前系统时间**（本机时区）计算后续运行时刻；
- 时间格式 `YYYY-MM-DD HH:mm`，带秒字段时显示 `HH:mm:ss`，等宽字体展示；
- 每行附相对提示（如「10 分钟后」「明天 09:00」），每 30 秒自动刷新；
- 点击「复制全部」可将结果以文本复制到剪贴板。

### 语义说明

- 周字段 `0` 和 `7` 均表示周日；
- 日与周同时指定时按 cron「OR」语义处理（满足其一即触发）；
- `0 0 31 * *` 在无 31 日的月份（如 2 月）自动跳过；
- `L`：日字段表示当月最后一天；周字段（如 `5L`）表示当月最后一个星期五；
- `W`：`15W` 表示距当月 15 日最近的工作日（15 日为周六取 14 日，周日取 16 日）；`LW` 表示当月最后一个工作日。

### 主题

- 默认跟随系统深浅色；
- 右上角提供三档切换：跟随系统 / 浅色 / 深色，选择会持久化保存（本地存储，不占用插件权限）。

## 数据说明

- 本插件为纯前端工具，不保存任何数据（仅主题选择保存在本地 localStorage）；
- 不需要也不使用 MixCore 的数据库/配置存储权限。

## 常见问题

- **输入 `@midnight` 报错？** 已支持，与 `@daily` 同义（每天 00:00）。
- **`0 0 31 * *` 显示的下一次为什么不是当月？** 当月若无 31 日会跳过，这是 cron 的正常语义。
- **为什么结果会每隔一段时间刷新？** 基于当前时间计算，每 30 秒自动重算，保证「N 分钟后」等相对提示准确。
- **复制全部没反应？** 若剪贴板 API 不可用，会自动回退到兼容方式；仍失败请检查系统剪贴板权限。
