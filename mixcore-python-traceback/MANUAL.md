# Traceback 分析器用户手册

## 快速上手

1. 在左侧“原始 Traceback”中粘贴 Python 异常日志；
2. 点击“格式化分析”，或按 \`Ctrl + Enter\`；
3. 在右侧查看解析后的调用栈与最终异常。

macOS 可使用 \`Command + Enter\` 快速分析。

## 查看调用栈

- 每个栈帧展示文件名、行号和函数名；
- 点击栈帧可展开或折叠完整路径与源码行；
- 项目代码默认展开，识别为依赖库的栈帧默认折叠；
- “展开全部”和“折叠全部”可批量控制所有栈帧；
- 最终异常显示在调用栈底部。

## 主题

顶部主题控件提供“跟随系统”“浅色”“深色”三种模式。选择结果会自动保存。

## 清空

点击“清空”会同时清除输入内容和本次分析结果。

## 无法解析

如果提示“未检测到调用栈”，请确认粘贴内容包含类似以下结构：

\`\`\`text
Traceback (most recent call last):
  File "app.py", line 12, in main
    run()
ValueError: invalid value
\`\`\`

仅包含普通日志、没有 \`File "xxx.py", line 10\` 栈帧的内容不会生成调用栈。
