# Hello World

MixCore 示例插件，用于演示插件商店的安装 / 更新 / 图标 / README 预览流程。

## 功能

- 打开一个独立窗口显示欢迎语
- 演示插件商店完整链路：索引 -> 下载 -> 安装 -> 更新

## 使用

1. 打开 MixCore **插件中心 -> 插件商店**
2. 点击 **安装**（或更新到最新版本）
3. 安装完成后在 **本地插件** 列表打开它

## 权限

| 权限 | 说明 |
| ---- | ---- |
| （无） | 本插件不需要额外能力 |

> 更多插件开发文档见 MixCore 仓库 `plugins/README.md`。
