# 快链接用户手册

## 产品简介

快链接插件把常用链接整理成卡片，支持关键词模板：链接中可带占位符，打开时填入参数自动生成目标地址。也能在超级面板用 #关键词 直接触发。

## 快速上手

「新建链接」填写名称和链接（支持 {keyword} 占位符），点击卡片即可在浏览器打开。

## 功能与操作

### 新建链接

1. **名称**：显示在卡片上；
2. **链接**：例如 https://github.com/search?q={keyword}，{keyword} 会在打开时被替换；
3. **关键词**（可选）：在超级面板输入 #关键词 可触发该链接；
4. **描述**（可选）：卡片上的补充说明。

### 打开链接

- 点击卡片或卡片上的打开按钮，使用系统默认浏览器打开；
- 链接含占位符时，会先弹出参数输入框，多个参数用**空格分隔**，分别替换到占位符中。

### 卡片操作

- **复制链接**：复制原始链接地址；
- **编辑 / 删除**：铅笔 / 垃圾桶按钮。

### 搜索

按名称、链接、关键词或描述过滤。

## 数据说明

- 链接数据保存在插件自己的数据目录（LMDB）；
- 删除或重装插件前请先备份。

## 常见问题

- **打开时提示“参数不完整”？** 链接里的占位符没有全部填上，重新打开并补全参数。
- **点击没反应？** 检查链接是否为 http / https 开头。

## 卸载说明

在「插件中心 → 已安装插件」中卸载，全部链接数据会被删除。
