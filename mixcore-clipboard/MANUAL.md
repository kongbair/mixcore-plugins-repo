# 剪切板用户手册

## 产品简介

剪切板插件记录系统剪贴板的历史内容（文本、图片、文件），支持搜索、收藏和快速复制。

## 快速上手

复制任意内容后打开插件，历史记录自动出现。点选列表项查看详情，双击或按 Enter 复制该项并关闭窗口。

## 功能与操作

### 历史列表

- 顶部筛选：**全部 / 文本 / 图片 / 收藏**；
- 搜索框按内容关键字过滤；
- 列表项显示类型图标、预览和时间（刚刚 / N 分钟前等）。

### 查看与复制

- 单击选中，右侧显示完整内容（文本全文 / 图片预览 / 文件路径）；
- 双击列表项或右侧「复制」按钮复制到剪贴板；
- 按 **Enter** 复制并自动关闭窗口；**↑ / ↓** 方向键切换选择。

### 收藏与清理

- 详情页「收藏」按钮收藏常用内容（再次点击取消），收藏项可在「收藏」筛选下查看；
- 「删除」删除单条记录；
- 顶部垃圾桶按钮「清空历史记录」清空所有记录（**收藏项保留**）。

### 实时同步

宿主监听到新复制内容时，插件会自动刷新列表。

## 数据说明

- 历史记录由 MixCore 宿主统一维护，插件只读展示；
- 清空历史会删除所有非收藏记录，且不可恢复。

## 常见问题

- **图片没有记录？** 部分应用复制图片可能不写入系统剪贴板记录，属系统限制。
- **清空后收藏还在吗？** 在，清空历史会保留收藏项。

## 卸载说明

卸载插件只移除插件本身，不会删除宿主维护的剪贴板历史。
