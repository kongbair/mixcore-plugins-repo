# 代码美化用户手册

## 产品简介

代码美化插件用于格式化 JSON、表格和数组数据，并以树形视图展示。打开时自动读取剪贴板内容，粘贴即格式化。

## 快速上手

打开插件后，左侧输入或粘贴内容，右侧自动生成格式化树视图；左右分栏的宽度可以拖动调整。

## 功能与操作

### 输入与格式化

- 左侧输入区粘贴 JSON / 表格 / 数组内容，右侧实时格式化；
- 工具栏「打开文件」可直接读取本地文件内容（仅限授权目录）；
- 「清空数据」按钮清空输入区。

### 搜索高亮

- 按 **Ctrl + F** 打开搜索框，输入关键词后树中命中项自动高亮；
- 使用上 / 下箭头按钮在命中项之间跳转，Enter 跳到下一个。

### 复制数据

点击「复制数据」弹出菜单：

| 选项                 | 说明                                    |
| -------------------- | --------------------------------------- |
| 完整复制             | 复制格式化后的完整内容（Ctrl + S 快捷） |
| 去重复制             | 数组去重后复制                          |
| 去重复制(转字符串)   | 数组去重并转为字符串后复制              |
| IN查询复制           | 生成 SQL 的 IN 查询片段                 |
| IN查询复制(转字符串) | 生成字符串形式的 IN 查询片段            |
| 多参查询复制         | 用空格分隔多个值，便于多参数查询        |

### 查看与排序

- **全部展开 / 全部收缩**：一键展开或收起树节点；
- **深度控制**：+ / - 调整展开层级；
- **排序**：按键名排序。

### 节点操作

右键任意节点：

- 复制 **value** / **key** / **path**；
- **表格显示**：数组字典类型可切换为表格视图，表格里可「复制 CSV」。

## 数据说明

- 输入内容只保存在内存中，关闭插件后不保留；
- 主题选择（浅色 / 深色）会被记住。

## 常见问题

- **提示“数据格式错误”？** 请检查输入是否为合法 JSON / 数组格式。
- **表格显示不可用？** 只有“数组且每个元素都是对象”的数据支持表格视图。

## 卸载说明

在「插件中心 → 已安装插件」中卸载即可，无残留数据。
